Chartwerk

PowerPoint-Add-in für Diagramme im Beratungsstil: Datenblatt wie Excel, automatische CAGR- und Differenzpfeile, Wasserfall, Mekko.

manifest.xml herunterladen

Installation auf dem Mac

  1. PowerPoint komplett beenden (⌘Q).
  2. Im Terminal: 
    mkdir -p ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef
curl -fsSL https://larschristianvogel-ops.github.io/chartwerk/manifest.xml \
  -o ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef/chartwerk.xml
  3. PowerPoint öffnen, eine Präsentation öffnen.
  4. Einmalig: Start > Add-Ins, unter „Entwicklertool-Add-Ins“ auf Chartwerk klicken. Danach ist der Reiter Chartwerk dauerhaft da.
